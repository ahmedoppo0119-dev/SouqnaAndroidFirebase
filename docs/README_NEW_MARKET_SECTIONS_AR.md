# تحديث سوقنا: السيارات والخامات والعقارات

تمت إضافة 3 أقسام إلى واجهة سوقنا:
- بيع عربيتك: ماركة/موديل، السنة والحالة، السعر، رقم التواصل، المحافظة والمنطقة والتفاصيل.
- بيع وشراء الخامات: اسم الخامة، التصنيف/الماركة/الوحدة، السعر، الكمية والحالة والتفاصيل.
- عقارات: نوع العقار، السعر أو الإيجار، المكان، المساحة والتفاصيل.

## مهم قبل استخدام الأقسام الجديدة
1. افتح لوحة مشروع Supabase ثم SQL Editor.
2. افتح الملف `SETUP_CARS_MATERIALS_REALESTATE_AR.sql` وانسخ محتواه إلى SQL Editor ثم اضغط Run مرة واحدة.
3. افتح التطبيق وسجّل الدخول بحساب مستخدم فعلي؛ النشر متاح للحسابات المسجّلة فقط.

الأقسام تعتمد على الجداول `car_listings`, `material_listings`, `real_estate_listings`.

## ملاحظة عن مشكلة الطلبات
هذا التحديث يضيف الأقسام الجديدة ولا يدّعي إصلاح خطأ `42501` في إرسال الطلبات. مشكلة الطلبات تحتاج فحص رسالة الخطأ الدقيقة من استجابة Supabase، لأن سياسات RLS الخاصة بالطلبات تم تعديلها بالفعل وما زال الخطأ يظهر.


تحديث إضافي: تمت إضافة رفع عدة صور لإعلانات سوق المستعمل أيضًا، مع معاينة الصور قبل النشر وحفظ روابطها في عمود image_urls. يجب إعادة تنفيذ ملف SETUP_CARS_MATERIALS_REALESTATE_AR.sql لتجهيز عمود الصور في قاعدة البيانات إن لم يكن موجودًا.
