إصلاح إرسال الطلبات — سوقنا

تم تعديل index.html ليستخدم الدالة souqna_create_order بدل طلب INSERT مباشر ثم INSERT منفصل لعناصر الطلب.
الدالة تنشئ الطلب وعناصره معًا في معاملة واحدة، وتتحقق من أن المحل موجود وأن كل منتج يتبع المحل المحدد.
هذا يتجنب الحاجة لمنح العملاء صلاحية SELECT عامة على الطلبات لمجرد استخدام INSERT ... RETURNING.

تم نشر الدالة على مشروع Supabase المتصل بالمحادثة. ملف SETUP_ORDER_RPC_FIX_AR.sql مرفق للتوثيق/إعادة الإعداد عند الحاجة.

التحقق: فحص ملفات ZIP وكود JavaScript؛ لم أرسل طلبًا تجريبيًا إلى بيانات الإنتاج، لذلك يلزم اختبار طلب حقيقي من التطبيق للتأكد من ظهوره عند التاجر.
